# Workbench visual assets

The pale technical workspace and lime/blue/magenta accents follow the supplied
Workbench and raven references. Controls and icons remain real HTML/SVG so they
stay selectable, accessible, and crisp at different zoom levels.

- `astra_harness/workbench_static/texture-reference.png` is an unchanged copy of
  the user-supplied collage, displayed with CSS background positioning.
- `astra_harness/workbench_static/menu-burst.png` is generated with the built-in
  **ChatGPT Images** tool, not the API/CLI fallback. It is a decorative transparent
  impact-burst backdrop; the five action buttons are not baked into the image.

## Final generation prompt

Use case: stylized-concept. Asset type: decorative transparent raster backdrop behind an interactive web context menu, not a mockup. Create a dynamic Japanese RPG / manga UI impact burst: angular black ink shards, acid neon yellow-lime lightning rays, a few white paper-cut slashes, offset halftone dots, rough screenprint texture. Tall asymmetric composition with the burst origin toward the middle left and spikes extending around an EMPTY vertical central area reserved for five real HTML buttons; graphic mostly along the perimeter. Sharp high-contrast Persona-inspired energy, restrained enough for a technical light gray CAD dashboard. Colors: near-black, white, #dfff00 with tiny cobalt accents. Actual transparent background, no gray checkerboard. No text, no letters, no numbers, no icons, no characters, no interface screenshot, no button labels. Portrait approximately 2:3 aspect ratio; all shards fully inside with transparent margin. This is a decorative production asset only.
